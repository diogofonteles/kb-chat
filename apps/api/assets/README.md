# API assets

`whisper-multilingual.tiktoken`: the vocabulary of Whisper's multilingual tokenizer, unchanged, from `openai/whisper` (MIT License, Copyright (c) 2022 OpenAI), as shipped in `mlx-whisper` 0.4.3 under `mlx_whisper/assets/multilingual.tiktoken`. SHA-256 `b34b360dbb493e781e479794586d661700670d65564001f23024971d1f2fa126`.

The API counts the term list with it (KBC-040 BR-2), so the limit on the screen is the one the transcriber's prompt has.
